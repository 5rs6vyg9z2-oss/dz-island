DZ Island

Uma ilha para acompanhar conexões, bateria dos dispositivos e avisos de agentes de IA.

↓ Baixar instaladorBaixar portátil

O Windows pode exibir um aviso de editor desconhecido.

Instalação

Abra o instalador para adicionar o DZ Island ao Menu Iniciar. Remova o programa em Aplicativos instalados do Windows.

Versão portátil

Extraia todo o ZIP e abra o arquivo DZ-Island.exe dentro da pasta extraída.

Atualizações

O aplicativo consulta as versões estáveis no GitHub do DZ Island e preserva suas configurações durante a atualização.
